# Feature 04 — Reconcile loop · mission phase0-stabilize

## Intent

Block state is maintained by four hand-written paths that disagree with each
other, and one of them loses data: a failed unblock still clears `is_blocked`,
so the router keeps dropping traffic forever with no retry. Replace all four
with one reconcile loop — compute the desired block state, diff it against
what the router last confirmed, enqueue the delta — so failures retry
naturally and startup resync falls out of the same mechanism.

## Scope — the ONLY files you may touch

- `src/streamguard.c`
- `src/streamguard.h`
- `test/unit/test_reconcile.c` (new)
- `test/Makefile`

## My assertions

- **A3**: when the firewall `del` fails, `is_blocked` stays 1 and a retry is
  scheduled; only a later *successful* retry clears it.
- **A4**: when the firewall `add` fails, the client is retried with
  exponential backoff, capped at `BLOCK_MAX_BACKOFF_MS`.
- **A8**: startup resync of a client whose block is inconsistent with its
  quota issues a firewall `del` **before** clearing local state (enforce mode).

All proven by `test/unit/test_reconcile.c` via `make -C src test-unit`.

## Pre-assembled context

The four paths you are replacing, all in `src/streamguard.c`:

- `block_client` (208-240) — on success sets `is_blocked=1`; on failure sets
  `is_blocked=1` anyway (to stop per-packet spam) and schedules a retry.
- `unblock_client` (243-263) — **the bug**: `clients[idx].is_blocked = 0;` is
  executed unconditionally, before the return code is examined:
  ```c
  int ret = execute_firewall_command("del", "blocked_streaming_clients", ip_str);
  clients[idx].is_blocked = 0;  /* Always clear - daily reset gives fresh start */
  if (ret == 0) { log_info("UNBLOCKED: ..."); }
  else { log_debug("Unblock %s returned %d (may not have been blocked)", ...); }
  ```
  There is no unblock retry anywhere in the file.
- `retry_pending_blocks` (266-291) — retries adds only, driven by
  `block_retry_after_ms` / `block_backoff_ms`.
- `resync_blocked_clients` (297-346) — startup pass; its "inconsistent block"
  branch (307-317) clears `is_blocked` locally **without** issuing a `del`:
  ```c
  if (clients[i].streaming_seconds < effective_quota) {
      log_warn("RESYNC: %s cleared inconsistent block ...");
      clients[i].is_blocked = 0;
      clients[i].block_retry_after_ms = 0;
      clients[i].block_backoff_ms = 0;
      cleared++; continue;
  }
  ```

Callers to update: `check_session_timeouts` (`:482`, `:497`) calls
`block_client`; `check_daily_reset` (`:376-378`) calls `unblock_client`;
`check_session_timeouts` ends with `retry_pending_blocks()` (`:503`);
`resync_blocked_clients` is called once during startup in `main()`.

**The replacement.** Add to `struct client_info` (`src/streamguard.h:70-86`):

```c
enum block_reason { REASON_NONE = 0, REASON_QUOTA = 1 };
/* new fields */
enum block_reason desired_block;  /* recomputed every tick */
uint8_t actual_block;             /* last state the router CONFIRMED */
```

Keep the existing `is_blocked` as the persisted mirror of `actual_block` so
`src/state.c` (out of scope) keeps working unchanged — set `is_blocked =
actual_block` whenever `actual_block` changes. Reuse the existing
`block_retry_after_ms` / `block_backoff_ms` fields for backoff of **either**
direction; they are not persisted, which is fine.

```c
STATIC enum block_reason compute_desired_block(int idx, uint64_t now_ms);
/* this mission: EXEMPT profile → NONE; accumulated + in-flight session time
   >= effective_quota_for(idx) → QUOTA; else NONE.
   (Feature 01 added effective_quota_for(). Later missions add curfew and a
   per-client enforce flag here — leave the shape ready for that.) */

STATIC void reconcile_clients(uint64_t now_ms);
/* for each in_use client:
     desired = compute_desired_block(i, now_ms);
     if (!!desired == actual_block) { clear backoff; continue; }
     if (now_ms < block_retry_after_ms) continue;          // backing off
     op = desired ? "add" : "del";
     ret = ops->execute(&cfg, op, "blocked_streaming_clients", ip_str);
     if (ret == 0) { actual_block = !!desired; is_blocked = actual_block;
                     block_retry_after_ms = 0; block_backoff_ms = 0; log … }
     else { backoff = block_backoff_ms ? block_backoff_ms
                                       : BLOCK_INITIAL_BACKOFF_MS;
            block_retry_after_ms = now_ms + backoff;
            block_backoff_ms = NEXT_BACKOFF(backoff);
            log_error(…); }                                 // actual_block UNCHANGED
*/
```

Dry-run (`enforce_mode == 0`): log the intended transition and set
`actual_block = !!desired` without calling the enforcer, preserving today's
dry-run behaviour.

Startup: after `load_state()`, initialise `actual_block = is_blocked` for every
loaded client and let the first `reconcile_clients()` call do the rest —
delete `resync_blocked_clients` entirely. A8 then holds by construction: a
client loaded as blocked whose usage is below quota computes
`desired = NONE`, `actual_block = 1`, so reconcile issues the `del` first and
only clears local state when the router confirms.

Call `reconcile_clients(now_ms)` once per maintenance tick, from where
`retry_pending_blocks()` is called today (`src/streamguard.c:503`). Remove
`block_client`, `unblock_client`, `retry_pending_blocks`,
`resync_blocked_clients` and their call sites. Keep the log message prefixes
(`BLOCKED:`, `UNBLOCKED:`, `QUOTA_EXCEEDED:`) — the dashboard and Andre's eyes
depend on them.

**Constants** (`src/streamguard.h:21-23`): `BLOCK_INITIAL_BACKOFF_MS` 5000,
`BLOCK_MAX_BACKOFF_MS` 300000, `NEXT_BACKOFF(b)` doubles with cap.

**Testing seam.** Feature 03 added `struct enforcer_ops` in `src/firewall.h`
with `firewall_real_ops`. Hold a `const struct enforcer_ops *g_enforcer` in
`streamguard.c`, defaulting to `&firewall_real_ops`, and expose a setter in
the `#ifdef TESTING` block of `src/streamguard.h` so the test installs a
recording stub that logs every `(action, ip)` and returns a scripted code.
Existing test helpers to reuse: `test_init_client`, `test_get_client`,
`test_clear_clients` (`src/streamguard.h:158-165`).

Time must be injectable: `reconcile_clients` and `compute_desired_block` take
`now_ms` as a parameter — never call `get_wall_time_ms()` inside them.
