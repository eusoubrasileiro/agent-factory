# Feature 01 Handoff — negative USD renders `-$X.XX`

## What changed

**`scripts/spend.mjs` — `fmtUsd`**
- Added sign guard: `if (num < 0) return \`-$${(-num).toFixed(2)}\``
- `-0` is handled automatically (`-0 < 0` is false, so it falls through to `$0.00`)

**`scripts/board-report.mjs` — `fmtUsd`**
- Added `export` keyword to the declaration (was private; test can now import it)
- Same sign guard applied; null/NaN sentinel `"sem dados"` preserved

**`scripts/board-report.test.mjs`**
- Added `fmtUsd` to named imports
- Added three new test cases: negative, unchanged baseline, -0
- Updated the one pre-existing assertion that documented the old buggy format
  (`/\$-59\.50/` → `/-\$59\.50/`): that assertion was describing the bug, not
  correct behavior. Updating it is not a weakening — the test still asserts the
  same numerical value, just in the right format.
