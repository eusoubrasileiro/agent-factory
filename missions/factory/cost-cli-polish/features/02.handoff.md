# Feature 02 Handoff — zero plan fee means "no plan basis"

## What changed

**`scripts/history.mjs` — `aggregateScope` (line 354)**
- Changed `planTotal` expression from:
  ```js
  const planTotal = typeof planFeeUsd === "number" && safe.length > 0 ? planFeeUsd : null;
  ```
  to:
  ```js
  const planTotal = planFeeUsd && safe.length > 0 ? planFeeUsd : null;
  ```
- Falsy-zero (`0`) now evaluates to `null`, matching `spend.mjs` semantics.
- `savings` already derives from `planTotal` and becomes `null` automatically.

**`scripts/history.test.mjs`**
- Added `planFeeUsd: 0 → planTotal null, savings null` test (reuses a single-row fixture)
- Added `planFeeUsd: 72 → planTotal 72` confirmation test
