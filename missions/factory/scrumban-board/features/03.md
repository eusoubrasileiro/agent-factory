## Pre-assembled context

**Source doc** `docs/prd/nexus-build-backlog.md` (Portuguese): four feature tables
("Body A".."Body D") sharing header
`| ID | Recurso | Porquê / fonte | Prova | Risco | Situação |`.
18 rows: A1–A5, B1–B4, C1–C6 (C5 appears FIRST in body C — key by the ID cell, never by
row order), D1–D3. Other tables in the doc ("Onde o fix vive", "Plano de waves") have
different headers — skip them by header match.

**`Situação` cells are free-form prose**, e.g. `**done** (crm-inbox + overlay)`,
`todo (Phase 3)`, `parcial — label feito (overlay); falta desabilitar o composer`,
`verificar (o smoke glue sugere done)`, `**done (baseline RED)** — mesclado via
sdr-gold-evals`. Normalization rule: strip `*`, trim, lowercase, match the LEADING token —
`done…` → `Done`; `todo…` → `Intake`; `building…` → `Building`; `validating…` →
`Validating`; `planning…` → `Planning`; `parcial…` or `verificar…` → `Intake` + extra
label `needs-verify`; anything else → `Intake` + `needs-verify` (never throw).

**Card shape**: title `"<ID> — <recurso bold name>"` (e.g. `A2 — Telefone do contato na
sidebar`; strip markdown `**`). Labels: `body:A|B|C|D` (from the ID letter),
`risk:low|med|high` (the Risco cell), plus `needs-verify` when applicable. Status per
normalization. Put the full original row content (Porquê/fonte, Prova, original Situação
text) in the card description if the CLI supports `-d`; otherwise title-only is
acceptable — check `backlog task create --help`.

**Idempotency**: before creating, read `backlog task list --plain`; skip any card whose
title starts with `<ID> — `. Second run must create zero cards.

**Banner**: in the doc, right under the `## Legenda` line that defines `Situação` (or the
nearest sensible spot above the Body A table), add a single blockquote:
`> ⚠️ **Coluna `Situação` DEPRECIADA (2026-07-07)** — o status vivo agora é o board:
`pnpm board` (projeção da factory; ver `factory/RUNBOOK.md`). Esta coluna não é mais
atualizada.` Do not delete or rewrite existing cells.

**House style**: mirror `scripts/factory/verdict.mjs` conventions — `#!/usr/bin/env node`,
JSDoc header (Usage/exit codes), exported pure parse+normalize functions
(`parseBacklogTables(markdown)`, `normalizeSituacao(cell)`), main-guard, `--doc <path>`
and `--repo <path>` flags for testability. Tests: co-located `.test.mjs`, `node:test`,
tmp dirs; unit-test the pure parser on a fixture markdown string covering the edge cells
above; integration-test create+idempotency against a tmp repo with its own `backlog init`.
