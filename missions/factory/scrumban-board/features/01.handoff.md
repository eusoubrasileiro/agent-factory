## Issues hit
- **Fresh worktree not bootstrapped.** Backend `tsc` and `quality-gate` first failed
  (cannot find `@wahub/shared`; `@prisma/client` missing exports; coverage read as 0).
  None caused by this feature. Fixed by bootstrapping: `pnpm --filter=@wahub/shared build`,
  `pnpm --filter=@wahub/backend exec prisma generate`, then `test:coverage` (both packages)
  to populate `*/coverage/coverage-summary.json` that quality-gate reads. A dispatched
  worktree needs these before the gate can run.
- **`backlog config set statuses` does NOT work in 1.47.x** — the CLI refuses array sets
  ("Array values should be edited in the config file directly. Use 'backlog config
  list-statuses' to view"). Set the 7 statuses by editing `backlog/config.yml` directly
  (a sanctioned, tool-directed path; not task frontmatter). `config set defaultStatus`
  still works. Spec's pre-assembled `config set statuses` recipe is stale for this version.
- **`backlog init` flag conflict**: `--integration-mode none` cannot be combined with
  `--agent-instructions none` ("Skipping AI integration cannot be combined with
  --agent-instructions"). Used `--agent-instructions none` alone to skip the agent files.
- **`pnpm lint` (biome) intermittently OOMs** ("Linter process terminated abnormally
  (possibly out of memory)", exit 254) under concurrent load — NOT related to `backlog/`
  (confirmed: `biome check backlog/` reports those paths already ignored; 3 consecutive
  clean runs passed). Environmental memory pressure; retry if it trips in CI/pre-push.
- Task IDs render uppercase (`TASK-1`) despite `task_prefix: task`; `--plain` list format
  is `<Status>:` header + 2-space-indented `<ID> - <title>`. Parsers handle it.
