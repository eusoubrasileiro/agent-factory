## Pre-assembled context

**verdict.mjs anatomy**: subcommands `record <slug>` (verdict JSON on stdin) / `status
<slug>`, optional `--dir <missions-root>`. The SINGLE durable write is in `cmdRecord`:
`appendFileSync(logPath(root, slug), ...)` followed by a `recorded round …` stdout line
and `return 0`. Insert the hook there — after the append, before the return.

**Hook shape (soft-fail, M-07)**: `spawnSync(process.execPath, [<abs path to
board-sync.mjs resolved relative to verdict.mjs>, slug, "--dir", root], { stdio:
"ignore" })` wrapped in try/catch; ignore status/errors entirely. It must not print,
must not alter exit codes, must not run at all if board-sync.mjs is missing. Resolve
board-sync's path from `import.meta.url` (same dir), NOT from cwd.

**Existing tests**: `scripts/factory/verdict.test.mjs` (node:test, spawnSync-based,
tmp-dir fixtures) must pass UNMODIFIED — run `node --test scripts/factory/verdict.test.mjs`
before and after. Your new tests go in `verdict-hook.test.mjs`, same style. For the
integration case, build a tmp repo dir with its own `backlog init` + a fixture mission +
card, run verdict record with `--dir`, assert the card's column via
`backlog task list --plain`. Also assert: with `backlog/` absent, record still exits 0
and appends the line.
