**Card ⇄ mission join (M-03)**: card title = the mission slug, label `mission`. board-sync
finds a card by exact title match in `task list --plain`; creates it (in the derived
column, labels `mission` + gate label if any) when a mission dir has no card.

**`deriveMissionState(missionDirPath) → { status, gateReason|null }`** — pure, first
match wins, top to bottom:

| Signal (files inside `factory/missions/<slug>/`) | Derived |
|---|---|
| `BLOCKED` file present | `Blocked` |
| `RATIFIED` file present | `Done` |
| `validate.log` last line verdict `PASS` | `Needs Human`, gate `gate:ratify` |
| last verdict `FAIL` and `round >= 3` | `Needs Human`, gate `gate:escalated` |
| last verdict `FAIL` and `round < 3` | `Validating` |
| `APPROVED` file + ≥1 `features/NN.md` and EVERY `features/NN.md` has `features/NN.handoff.md` | `Validating` |
| `APPROVED` file present (handoffs incomplete or no features yet) | `Building` |
| `brief.md` AND `contract.md`, no `APPROVED` | `Needs Human`, gate `gate:approve-plan` |
| `brief.md` only | `Planning` |
| anything else (dir with only `RESEARCH.md`/`PREVIEW.md`/etc.) | `Intake` |

`validate.log` is JSONL — one compact JSON object per line:
`{"slug":"…","round":1,"verdict":"PASS"|"FAIL","assertions":[…],"escalate":false,…}`.
Real mission dirs are messy (extra files like `OPERATOR.md`, `attention.md`,
`screenshots/`) — ignore unknown files, never throw.

**Gate label handling**: the gate reason rides a task label (`gate:ratify` |
`gate:escalated` | `gate:approve-plan`). On status change, set/replace the gate label;
remove stale gate labels when leaving `Needs Human`.

**Shell behavior** (`board:sync [slug] [--dir <missions-root>]`): scan all mission dirs
(or one slug); read cards via `task list --plain`; edit ONLY when derived differs from
current (idempotent, quiet when clean); print one line per move
(`<slug>: <old> -> <new>`); after syncing, count columns and WARN (stderr, still exit 0)
if `Needs Human > 5` or `Building + Validating > 3`. Exit codes: 0 ok (warnings
included), 1 unexpected error, 2 usage. If `backlog/` does not exist: print a note,
exit 0 (soft layer). Backlog CLI runs with cwd = repo root of the tree being synced
(derive it from the missions root's parent or `--repo` flag — your call, keep it testable
against a tmp repo that has its own `backlog init`).
