# Feature 01 — Traceability model (pure core)

> Worker contract: TDD (RED test first, then GREEN, then refactor). House style =
> `scripts/factory/board-sync.mjs`: `#!/usr/bin/env node`, JSDoc, pure exported core +
> thin IO, main-guard `import.meta.url === pathToFileURL(process.argv[1]).href`.
> When done: run the pre-commit gate (`pnpm test:factory`, `pnpm lint`), commit, then
> write `factory/missions/factory-dashboard/features/01.handoff.md` (what you built,
> files, test count, anything the next worker must know).

## Deliverables
New file `scripts/factory/board-report.mjs` (model layer only — NO HTML yet) exporting:

1. `parseRequirementsLine(briefMarkdown) -> string[] | null`
   - Scans brief.md text for a line matching `**Requirements:** <value>` (tolerate
     leading `>`/whitespace, case-insensitive key).
   - `<value>` = comma-separated backlog IDs (`A1`…`D3`, pattern `/^[A-D]\d+$/` after
     trim) → return the array. `none` (any case) → `[]`. No line found → `null`.
   - Invalid tokens are skipped (never throw).
   - HARD RULE: this is the ONLY source of requirement↔mission mapping. Never scan
     contract.md/plan.md — their local IDs (e.g. role-funcionario's C1–C3) are
     acceptance-criteria labels, not backlog references.

2. `collectGitInfo(repoRoot) -> { branches: [{ name, slug, merged, lastCommitISO }] }`
   - `agent/*` branches via `git branch --format='%(refname:short)'`;
     `slug` = name without `agent/` prefix;
     `merged` = `git merge-base --is-ancestor <branch> main` exit 0;
     `lastCommitISO` = `git log -1 --format=%cI <branch>`.
   - Missing git / no branches → `{ branches: [] }` (never throw).

3. `buildTraceabilityModel({ missionsDir, prdPath, gitInfo }) -> model`
   - Requirements: `parseBacklogTables(readFileSync(prdPath))` from
     `./board-import-backlog.mjs` (already exported — reuse, do not copy) +
     `normalizeSituacao` for the fallback status.
   - Missions: for each dir in `missionsDir`: `deriveMissionState(dir)` from
     `./board-sync.mjs` (reuse), `parseRequirementsLine` of its brief.md (missing
     brief → null), features = `features/*.md` count (exclude `*.handoff.md`),
     handoffs = `features/*.handoff.md` count, lastVerdict = last JSONL line of
     `validate.log` if present (`{verdict, round}`), branch = matching gitInfo entry.
   - Model shape:
     ```js
     {
       generatedAt,            // ISO string
       requirements: [{ id, recurso, risco, situacao,       // from PRD
                        missionSlug|null, liveStatus }],     // liveStatus = linked
                                                             // mission's derived status
                                                             // else normalized situacao
       missions: [{ slug, status, gateReason, requirements,  // string[]|null
                    features, handoffs, lastVerdict|null,
                    branch: {name, merged, lastCommitISO}|null }],
       orphanBranches: [ ...gitInfo branches with no mission dir ]
     }
     ```
   - Tolerate every real shape: brief-only, RESEARCH.md/PREVIEW.md-only (no brief →
     requirements null), no features/, missing validate.log.

## Tests — new file `scripts/factory/board-report.test.mjs` (node:test, mkdtempSync fixtures)
Minimum cases:
- parseRequirementsLine: valid list; `none` → []; absent → null; invalid tokens
  skipped; line inside a blockquote.
- COLLISION GUARD: fixture mission with contract.md containing "C1"/"C2" and brief.md
  WITHOUT a Requirements line → model shows requirements null and no backlog row maps
  to it.
- Model statuses agree with deriveMissionState for: brief-only fixture (Planning),
  validate.log PASS fixture (Needs Human + gate:ratify), RATIFIED fixture (Done).
- Branch join: branch matching a mission slug attaches; orphan branch lands in
  orphanBranches; mission without branch → branch null. (Build a throwaway git repo in
  tmp via `git init` + commits, or inject a fake gitInfo object — injection is fine,
  collectGitInfo itself can be smoke-tested against the real repo read-only.)
- Requirement liveStatus: mapped row inherits mission derived status; unmapped row
  falls back to normalizeSituacao of its PRD cell.
