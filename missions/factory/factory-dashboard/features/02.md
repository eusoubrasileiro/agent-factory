# Feature 02 — HTML renderer + CLI shell

> Worker contract: TDD. Read `features/01.handoff.md` first. Extend
> `scripts/factory/board-report.mjs` (model layer landed in feature 01). When done:
> gate, commit, write `features/02.handoff.md`.

## Deliverables

1. `renderDashboardHtml(model) -> string` exported from `board-report.mjs`.
   ONE self-contained HTML document: ALL CSS in one `<style>`, ALL JS in one inline
   `<script>` (vanilla — no framework, no CDN, zero external URLs). Escape all
   interpolated text (`&<>"'`). Portuguese UI. Light, clean visual (system font
   stack, subtle borders, generous whitespace; status colors: Done=green,
   Needs Human=amber, Building/Validating=blue, Planning=gray, Blocked=red,
   Intake=neutral).

   Layout — header "Fábrica Nexus — rastreabilidade" + tab bar, footer
   `gerado em <generatedAt> · board-report`:

   - **Tab "Requisitos"** (default): one table per body A–D ("Corpo A — Inbox", B —
     Dashboard/CRM, C — SDR/Bot, D — Mineração). Columns: ID · Recurso · Risco
     (badge) · Status vivo (colored badge from liveStatus) · Missão (slug, clicking
     jumps to its mission card; or "sem missão" muted).
   - **Tab "Missões"**: status lanes in order Needs Human · Building · Validating ·
     Planning · Intake · Done · Blocked (empty lanes hidden). Card: slug,
     gateReason badge if any, `handoffs/features` progress (e.g. "2/4"),
     branch name + "mergeado"/"não mergeado" + last-commit date (DD/MM), linked
     requirement IDs as chips. Card click toggles a drill-down: features list,
     último veredicto (PASS/FAIL + round) if any.
   - **Orphan branches**: small section at the bottom of Missões when
     `orphanBranches` is non-empty ("branches sem missão").

   The model is embedded as `<script type="application/json" id="model">` for
   debugging, but the HTML itself must be fully rendered server-side (works with JS
   disabled except tab switching/drill-down).

2. CLI shell (main-guard) in `board-report.mjs`:
   `node scripts/factory/board-report.mjs [--missions-dir <p>] [--prd <p>] [--out <p>]`
   Defaults: `factory/missions`, `docs/prd/nexus-build-backlog.md`,
   `dist/factory-board/index.html` (mkdir -p the dir). Prints one summary line
   (`board-report: N requisitos, M missões -> <out>`), exit 0; exit 1 on unreadable
   PRD. Ensure `dist/` is gitignored (add if missing).

## Tests (extend `board-report.test.mjs`)
- Renders a fixture model: all requirement IDs present; "sem missão" for unmapped;
  mission slug appears in its lane; gate badge text present.
- Self-contained: output contains no `src="http`, no `href="http` (allow `href="#`).
- Escaping: a fixture recurso containing `<b>&"` arrives escaped.
- CLI: run via spawnSync against a tmp fixture tree → exit 0, file written, summary
  line matches; missing PRD → exit 1.
