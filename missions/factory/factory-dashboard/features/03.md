# Feature 03 — Publish script + deploy artifacts

> Worker contract: read `features/02.handoff.md` first. TDD where testable (the
> dry-run path). When done: gate, commit, write `features/03.handoff.md`.

## Deliverables

1. `scripts/factory/board-publish.sh` (bash, `set -euo pipefail`):
   - Preflight: `dist/factory-board/index.html` exists (else exit 1 with a hint to run
     `pnpm board:report`).
   - `--dry-run`: print the exact rsync command and exit 0 — NO network, NO ssh.
   - Real run: `rsync -az --delete dist/factory-board/ deploy-host:/opt/app/factory/public/scrumban/`
     then echo the URL `https://factory.example.com/scrumban/`.
   - Overridable via env: `PUBLISH_HOST` (default `deploy-host`), `PUBLISH_DIR`
     (default `/opt/app/factory/public/scrumban/`).

2. `deploy/factory-board/docker-compose.yml` — mirror the
   `products/lead-searcher-deploy/docker-compose.yml` pattern (read it at
   `../../lead-searcher-deploy/` relative to repo parent — if unreadable from the
   worktree, the pattern is fully specified here):
   ```yaml
   services:
     factory-board:
       image: nginx:alpine
       restart: unless-stopped
       volumes:
         - ./public:/usr/share/nginx/html:ro
       networks: [network_public]
       labels:
         - traefik.enable=true
         - traefik.http.routers.factory.rule=Host(`factory.example.com`)
         - traefik.http.routers.factory.entrypoints=websecure
         - traefik.http.routers.factory.tls.certresolver=myresolver
         - traefik.http.routers.factory.middlewares=factory-auth
         - traefik.http.middlewares.factory-auth.basicauth.users=${FACTORY_BASICAUTH}
         - traefik.http.services.factory.loadbalancer.server.port=80
         - traefik.docker.network=network_public
   networks:
     network_public:
       external: true
   ```
   NEVER commit an htpasswd hash or a real `.env` — `${FACTORY_BASICAUTH}` stays a
   variable; add `deploy/factory-board/.env` to .gitignore.

3. `deploy/factory-board/DEPLOY-VPS.md` — short runbook:
   one-time (Andre): Cloudflare A-record `factory` → `69.62.103.190` DNS-only/gray
   (Traefik does ACME); `htpasswd -nb <user> '<pass>'` ×3 (andre, tenant-a, operator),
   join with commas, double every `$` to `$$`, put in `/opt/app/factory/.env` as
   `FACTORY_BASICAUTH=...`; `mkdir -p /opt/app/factory/public/scrumban`; scp the
   compose file; `docker compose up -d`. Recurring: `pnpm board:report && pnpm
   board:publish` (bind mount ⇒ no restart).

4. Root `package.json` scripts:
   `"board:report": "node scripts/factory/board-report.mjs"`,
   `"board:publish": "bash scripts/factory/board-publish.sh"`.

## Tests (extend `board-report.test.mjs` or new `board-publish.test.mjs`)
- spawnSync `bash scripts/factory/board-publish.sh --dry-run` with a fixture dist dir
  (use `PUBLISH_*` env + a cwd trick or create `dist/factory-board/index.html` in a tmp
  copy — simplest: run with env `PUBLISH_HOST=testhost` and assert the printed command
  contains `testhost:` and `rsync -az --delete`) → exit 0.
- Missing dist → exit 1.
- `docker compose -f deploy/factory-board/docker-compose.yml config` with
  `FACTORY_BASICAUTH=dummy` exits 0 (skip the test with a note if docker is
  unavailable in the sandbox — the validator machine has it).

## Do NOT
- ssh/rsync to any real host anywhere in tests or dry-run.
- Touch generator/model code.
