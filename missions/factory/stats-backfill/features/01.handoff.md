# Handoff — feature 01  ·  mission stats-backfill

> **Author: builder (caged GLM-5.2). Reader: validator + coordinator.** Facts, not prose.

## What I built

Two files, touching nothing else (contract: "ONE new file + its test"):

- **`scripts/stats-backfill.mjs`** — thin, repeatable driver. Computes NO stats; it
  delegates every number to the existing `collect` (imported from
  `mission-stats.mjs:518`) and only decides *what* to collect + reports coverage.
  House style (cf. `board-sync.mjs`): pure exported core + thin CLI shell, per-line
  try/catch tolerance, JSDoc headers explaining WHY.

  Exports (all but the last are the testable pure/injectable cores; A6):
  - `planBackfill(rootDir, projects, opts)` → `{ work, skipped }` — PURE: walks the
    dossier tree, writes nothing, runs no git. Partitions dossiers into `work`
    (collect needed) vs `skipped` (`kind:"had"` already-has-stats without `--force`;
    `kind:"unknown-project"` non-profile dir under `missions/`). Selection:
    `opts.project` → that one known profile dir; else `--all`/default → every known
    profile dir. Non-dot dirs + dot-dirs are dropped (A2). Deterministic order
    (project id asc, slug asc).
  - `runBackfill(plan, collectFn, emit)` → `{ backfilled, failed }` — calls the
    INJECTED `collectFn` once per work item; a throw → `{slug,error}` in `failed`,
    continue, **no stats.json written** (A3 / E1-d "absent, never zero").
  - `formatReport(plan, results)` → `string[]` — PURE: `project=<id> dossiers=<n>
    had=<n> backfilled=<n> failed=<n>` per project (id asc) + final
    `total: X/Y with stats` (X = had+backfilled, Y = dossiers). Pins A4 exactly.
  - `parseArgs(argv)` → `{ project, all, force, missions, bad }`.
  - `main(argv, deps)` → exit code (0 completed · 2 bad args / unknown `--project`),
    effects injected via `deps.{out,err,projects,collect}` so tests drive it without
    git. The production `collectFn` adapts each work item to `collect`'s signature,
    resolving `repoRoot` via `resolveProject` (so real runs do git LOC; in this
    worktree product repos are unreachable → git-derived fields degrade to null/0,
    which is correct/total).

- **`scripts/stats-backfill.test.mjs`** — node:test + node:assert/strict, tmpdir
  fixtures (mkdtempSync + `finally` rmSync, house convention), generic ids
  (`alpha`/`beta`) only. Fake `collectFn` injected; real git never touched.

## Mutation-gate analysis (the two the contract names)

- **A1 guard:** the skip branch is `if (hasStats && !force) skipped.push({kind:"had"…})`.
  Removing that branch (the canonical "remove the existsSync guard") sends a
  had-stats dossier into `work`, so `A1 no-clobber…` asserts `!work.includes("done")`
  → goes RED. ✔ gate effective.
- **A3 catch:** the `catch` only `failed.push({…,error})` + `emit`; it writes no file.
  The `A3 collect throw…` test asserts `!existsSync(stats.json)`. If the catch is
  mutated to `writeFileSync(statsPath, <zeros>)`, that assertion goes RED. ✔ gate
  effective. (By construction the driver writes **no** stats.json itself — only
  `collect`/the injected `collectFn` does — so A3 "passes through verbatim" holds.)
