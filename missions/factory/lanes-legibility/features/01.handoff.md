### F2 — split Needs Human (presentation only; `deriveMissionState` untouched here)
- **A1** `laneOf(m)` maps the Needs-Human population by `gateReason` into three
  lanes — **Aprovar plano** (`gate:approve-plan`), **Aprovar merge**
  (`gate:ratify`), **Escalado** (`gate:escalated`) — plus a **Needs Human (outro)**
  fallback for a null/unknown gate (never dropped). Lanes render in that order via
  `MISSION_LANES`. The `data-status="Needs Human"` hook is kept on every sub-lane
  so existing audits still match.
- **A2** A `<p class="needs-human-counts">` line atop Missões:
  `N para aprovar plano · N para aprovar merge · N escalados`, zero-count parts
  omitted (absent entirely when no Needs Human). Counts are taken off the *render*
  lane, so a merged mission (which left for Done) is not counted as "para aprovar
  merge".
- **A3** Lane headings stay `<h2>` (Done lane keeps `<h2>Done</h2>`; the audit-A3
  test stays green).

### F3 — honest lane semantics
- **B1** The Intake lane heading renders as **Sem contrato** (display only; the
  model status string stays `"Intake"`, `data-status="Intake"`).
- **B2** A Sem-contrato card whose `stats.json` has any token/LOC spend
  (`hasSpend`) shows a **trabalho iniciado** chip — never a bare "not started"
  next to real spend.
- **B3** `deriveMissionState` returns `{status:"Parked"}` for a `PARKED` marker
  (any content, weighed before BLOCKED/RATIFIED). The renderer folds Parked
  missions into a collapsed `<details class="estacionado">` **Estacionado**
  section below the active lanes, never inside them.

### MERGED ⇒ Done (Plan A ratified decision 1)
- **C1** `laneOf` routes `branch.merged === true` to the Done lane regardless of
  gate. A merged mission without a `RATIFIED` marker carries a **não ratificado**
  chip (`title="mergeado sem ratificação registrada"`). The model exposes
  `ratified: existsSync(RATIFIED)` so the chip reflects the real marker, not a
  status proxy.
- **C2** A merged mission's card is the same `renderMissionCard`, so its last
  verdict line is preserved.
