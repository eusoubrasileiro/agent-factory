# Feature 04 — History snapshots + Histórico tab

> Worker contract: TDD. House style = `scripts/factory/board-sync.mjs`. When done:
> `pnpm test:factory`, `pnpm lint`, commit, write
> `factory/missions/factory-live-board/features/04.handoff.md`.

## Deliverables

1. NEW `scripts/factory/history.mjs`:
   - `snapshotRows(model, project, ts)` → rows `{ts, project, slug, state,
     features:"m/n", rounds, verdict, reqIds}` (one per mission in the model; rounds =
     max validate.log round or 0; verdict = last verdict or null; reqIds from the
     Requirements join or []).
   - `appendSnapshots(historyPath, rows)` → JSONL append (mkdir -p parent).
   - `readHistory(historyPath)` → parsed rows, tolerant of a corrupt/partial line
     (skip, never throw), missing file → [].
   - `aggregate(rows, {now})` → per-project + global stats: missõesConcluídas
     (slug reaching Done, deduped), missõesPorSemana (Done slugs / weeks between first
     and last snapshot, min 1 week), leadTimes per Done slug (first snapshot ts → first
     Done snapshot ts) + median, rondasMédia, and — reading each mission's
     metrics.jsonl when a missionsDir is provided — tokensTotal and
     atençãoPorFeature = (touchpoint+intervention+escalation) ÷ handoff count.
   - Refactor `board-autopublish.mjs` to use snapshotRows/appendSnapshots (replace the
     inline feature-02 implementation — keep tests green).

2. `board-report.mjs` renderer: NEW third tab **Histórico** (PT-BR, consistent with
   existing tabs): stat cards (missões concluídas, missões/semana, lead time mediano,
   rondas média, tokens, atenção-por-feature) + a per-mission table (slug, estado
   atual, lead time, rondas, último verdict, data). Data injected via the embedded
   JSON blob like the other tabs. NO history.jsonl or empty → tab renders "sem dados
   ainda" (contract A6, never crash). CLI gains `--history <path>` (default
   `factory/history.jsonl` under --repo).

## Tests — NEW `scripts/factory/history.test.mjs` + renderer cases
- snapshotRows shape exact; appendSnapshots appends (no rewrite); readHistory skips a
  corrupt line.
- aggregate: fixture of 3+ snapshots across 2 missions, one reaching Done → correct
  lead time, missões/semana, rondas; missing metrics.jsonl → tokens/atenção "sem dados".
- Renderer: fixture history → Histórico tab greps for the computed values; empty →
  "sem dados ainda".

## Do NOT
- Change snapshot row shape (fixed in plan.md).
- Add charts/external libs — cards + table only, self-contained.
