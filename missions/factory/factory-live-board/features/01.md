# Feature 01 — Missions enter git (flip + hooks safety)

> Worker contract: TDD (RED test first where testable, then GREEN, then refactor).
> House style = `scripts/factory/board-sync.mjs`. When done: run `pnpm test:factory`,
> `pnpm lint`, commit, then write
> `factory/missions/factory-live-board/features/01.handoff.md`.

## Deliverables

1. `.gitignore`: remove the `factory/missions/**` ignore line (keep its comment block
   updated: missions are now committed — they are the spec of record). ADD ignores for
   `factory/.publish.log`. Verify `deploy/factory-board/.env` and `dist/` remain ignored.

2. `.husky/pre-commit` — add a fast-path guard at the TOP: collect staged paths via
   `git diff --cached --name-only`; if every path matches `^factory/missions/` or
   `^factory/history\.jsonl$`, echo a one-liner ("factory fast-path: docs-only commit")
   and `exit 0` BEFORE lint-staged/tsc/tests. Any other staged path → full gate runs
   unchanged. Do NOT touch commit-msg (commitlint must still run — it is a separate hook).

3. `scripts/factory/verdict.mjs`:
   - Every recorded verdict line gains `ts` = new Date().toISOString() (added at record
     time; validateVerdict tolerates but does not require it on input).
   - After a successful record + syncBoard: `autoCommit(root, slug, message)` — a new
     small helper (soft-fail, try/catch, never affects exit code) that runs
     `git commit -m "chore(factory): verdict <slug> round <n> <PASS|FAIL>" -- factory/missions/<slug> factory/history.jsonl`
     (pathspec-limited; `git add -A -- <paths>` first so new files are included; if
     nothing staged or git unavailable → silent skip).

4. `scripts/factory/ratify.mjs`: same autoCommit after writing RATIFIED, message
   `chore(factory): ratify <slug>`. Extract the helper into a small shared module
   (e.g. `scripts/factory/git-autocommit.mjs`) — do not duplicate.

## Tests — extend/new `scripts/factory/*.test.mjs` (node:test, mkdtempSync + `git init` fixture repos)
- verdict record output line contains valid ISO `ts`.
- autoCommit: in a fixture repo, commits ONLY the pathspec'd files even when other
  files are dirty; silent no-op when nothing to commit; silent no-op outside a git repo.
- Guard logic: extract the staged-paths predicate into a testable helper if written in
  JS, or test via fixture commits in the worktree (document in handoff which).

## Do NOT
- Touch board-report.mjs / board-publish.sh (features 02–03).
- Create board-autopublish.mjs (feature 02).
- Commit the existing mission backlog dirs (feature 05 does the backfill).
- Use `--no-verify` anywhere, ever.
