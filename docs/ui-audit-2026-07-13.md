# Factory Board — Adversarial UI Audit (2026-07-13)

**Method.** Three parallel Sonnet 4.6 validators, each in an isolated Playwright browser,
drove the entire board (`/`, `/factory/`, `/wahub/`, `/tenant-c/`, `/scrumban/`) across
mobile/tablet/desktop, took full-page screenshots, and read their own screenshots to judge
with their eyes. Coordinator (Opus) led, reasoned, deduplicated, and verified each finding
against the source before accepting it.

- **V1** — responsive & layout integrity (11 findings)
- **V2** — interaction, state & navigation (7 findings)
- **V3** — content correctness & accessibility (10 findings)

Raw reports: `scratchpad/v{1,2,3}/…/FINDINGS.md`. 28 raw findings → **13 distinct** after dedup.

---

## Verdict

**Not shippable as-is.** The board actively lies about cross-project data: the Histórico tab
renders a global mission dump on every board, and one project's kanban absorbs another's work.
Everything else is layout/a11y polish. Desktop & tablet are otherwise sound; **mobile is broken**.

---

## CRITICAL — cross-project data contamination (two independent root causes)

### C1 · Histórico never filtered by project *(code defect)*
`board-report.mjs main()` reads a single shared `factory/history.jsonl` and aggregates **all**
rows with no `--project` filter (line ~1398). Result: factory and wahub Histórico are
byte-identical (both show all 37 missions + the same $15.01/$72 KPIs); tenant-c — which owns
zero history rows — inherits everyone's data.
- Corroborated independently by V2-F1 and V3-F1.
- **Fix:** filter rows to `resolved.id` before `aggregate()`. Stat cards derive from the same
  array and self-correct. *(Test-first: pure `filterHistoryByProject` helper.)*

### C2 · Five factory dossiers mis-filed under `missions/wahub/` *(data defect)*
`factory-dashboard`, `factory-extract`, `factory-live-board`, `factory-secret-min`,
`scrumban-board` physically live in `missions/wahub/`, so history stamps them `project: wahub`
and they appear in wahub's Missões kanban (V3-F2). The board renders mis-filed data faithfully.
- **Fix:** `git mv` the five dossiers to `missions/factory/`, regenerate history snapshot.
- *Data-ownership call — flagged for André. Clearly factory-engine work by name; reversible.*

> C1 makes each board show only its own rows; C2 ensures those rows are tagged to the right
> project. Both are needed for the boards to tell the truth.

## Rejected on verification
- **V3-F9** (inactive panels in a11y tree): panels use the `hidden` *attribute* (`panel.hidden=…`),
  which **does** remove them from the accessibility tree. V3's evidence was a `querySelectorAll`
  DOM dump, which sees hidden nodes — not the a11y tree. No defect.
